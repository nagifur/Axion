# Axion

Axion Labs is a fictional facility database and worldbuilding project for my original characters. Explore its personnel, entities, synthetics, articles, and facility.

**Visit the website: [www.axionlabs.art](https://www.axionlabs.art)**

## Contributions

Corrections and fixes are welcome! New character and entity submissions are reserved for [Patreon](https://www.patreon.com/nagifur) supporters.

See the site's [submission page](https://www.axionlabs.art/submit) for submissions, or the [content templates](templates/README.md) for help preparing a character profile.

## Technical Details

Built with [Astro](https://astro.build/) and deployed to GitHub Pages through GitHub Actions.

Local setup, content formatting, and maintenance notes are in the [development guide](docs/DEVELOPMENT.md).
